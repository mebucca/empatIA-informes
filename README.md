# Estudio EmpatIA

Estudio anual sobre cómo las marcas equilibran **humanidad** y **tecnología** para
conectar con las personas en Chile. Producido por **dobleA** y **Better Brands**.

Este repositorio publica los documentos del estudio. El análisis y los datos viven
aparte, en un repositorio privado.

**→ [mebucca.github.io/empatIA-informes/](https://mebucca.github.io/empatIA-informes/)** es la portada, y el enlace que conviene compartir.

El **informe** se lee sin conocimiento técnico: cada cifra viene con cómo interpretarla
y con el margen que tiene. El **apéndice** documenta fórmulas, supuestos y límites. El
**kit de prensa** reúne el bloque de inteligencia artificial con cada cifra lista para
citar, y existe desde la edición 2025.

El informe de la fila «Todas» es el longitudinal: recorre las mismas preguntas del
informe anual, en el mismo orden, pero comparando las cuatro ediciones entre sí.

## Cómo se lee el estudio

El estudio es una **encuesta a una muestra**, repetida cada año con personas distintas.
Tres consecuencias que conviene tener presentes:

- Las cifras traen un **margen**. Diferencias pequeñas entre marcas o entre años pueden
  deberse a quiénes respondieron esta vez. El informe y los tableros indican cuándo una
  diferencia supera ese margen.
- Los análisis de preferencia establecen **asociación, no causa**. Percepción y
  preferencia se preguntan en la misma entrevista.
- El **Índice EmpatIA combina dos atributos** —«Es cercana» y «Es tecnológica»— con
  pesos definidos por el estudio. Es distinto de los bloques en que se agrupan los
  atributos para leer la experiencia; comparten nombre en un caso, pero no son lo mismo.
